# Pruebas responsive

Se consideran los siguientes anchos de referencia:

- Móvil: 390 px
- Tableta: 768 px
- Escritorio: 1440 px

## Verificaciones

- No existe desplazamiento horizontal.
- El menú se transforma en botón en pantallas pequeñas.
- El hero cambia de dos columnas a una columna.
- Las tarjetas de animales se reorganizan.
- Los diálogos caben dentro de la ventana.
- Los botones conservan un área táctil cómoda.
- El contenido permanece legible con zoom del navegador.
- El flujo de privacidad habilita la descarga únicamente después de aceptar.

Ejecuta:

```bash
npm test
```
