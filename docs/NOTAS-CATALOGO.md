# Notas de integración del catálogo de adoptables

La página `adoptables.html` se actualizó con las 14 fichas incluidas en el documento `catalogo adoptables.pdf` proporcionado por ARCY.

## Criterios usados

- Se tomó como fuente principal el texto narrativo de cada página.
- Se usaron fotografías incluidas dentro del mismo catálogo.
- No se inventaron edades, compatibilidades ni condiciones de salud.
- Cuando el texto y el material gráfico no coinciden, el sitio evita mostrar el dato como definitivo o utiliza el dato del texto narrativo.
- La disponibilidad debe confirmarse por WhatsApp antes de iniciar el proceso.

## Datos que ARCY debe confirmar

- **Canalito:** el texto narrativo indica 7 meses y una pieza gráfica indica 5 meses. El sitio utiliza 7 meses.
- **Eli:** el texto narrativo indica 5 meses y una pieza gráfica indica 3 meses. El sitio utiliza 5 meses.
- **Panterita:** el texto narrativo indica 5 meses y una pieza gráfica muestra otra edad y el nombre "Panda". El sitio utiliza el nombre Panterita y 5 meses, como aparece en el texto principal de la ficha.
- **Pulgarcita:** el texto narrativo indica aproximadamente 7 meses y una pieza gráfica indica 1 año y medio. El sitio muestra "Edad por confirmar".
- **Colmillo:** el título de la ficha dice Colmillo, pero el texto menciona el nombre Manchego. El sitio utiliza Colmillo y no reproduce el nombre contradictorio.
- **Sol:** una pieza gráfica indica 4 meses, pero el texto narrativo no confirma su edad actual. El sitio muestra "Edad por confirmar".

Antes de publicar una actualización futura, conviene validar estos datos con la persona responsable del catálogo.
